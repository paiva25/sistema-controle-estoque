# Sistema de Controle de Estoque

Projeto desenvolvido em linguagem C como atividade acadêmica do curso de Sistemas de Informação.

## Sobre o projeto

Sistema desenvolvido para realizar o controle de produtos em estoque, permitindo trabalhar com informações como nome, quantidade e preço dos produtos.

## Funcionalidades

- Cadastro de produtos
- Armazenamento das informações dos produtos
- Controle da quantidade em estoque
- Registro do preço dos produtos
- Cálculo de valores relacionados ao estoque

## Conceitos utilizados

- `struct`
- Ponteiros
- Alocação dinâmica de memória
- `malloc`
- `free`
- Funções
- Arrays
- Entrada e saída de dados
- Estruturas de repetição
- Lógica de programação

## Tecnologias

- Linguagem C
- GCC

## Objetivo

Praticar conceitos fundamentais e intermediários da linguagem C, especialmente estruturas (`struct`), ponteiros e gerenciamento dinâmico de memória.
